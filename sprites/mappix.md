# Mappix — Poke-issue-dex №60

*The Strategy Pokémon*

![Mappix](mappix.png)

**Type:** plan

**Rank:** legendary

**Species:** Strategy Pokémon  
**Height:** 0.5 m   **Weight:** 2.0 kg

> Mappix is a cartographer poke-issue that dreams the Region into terrain: it redraws the board's lanes as a hand-pixeled overworld map — routes, gym towns, and habitats — using the layering tricks classic Pokémon games used to imply depth and place. It carries a lantern that lets an issuemon 'travel' from one location to the next as it is handed between agents, and it insists the old lane view stay walkable so trainers can toggle between the list and the world. Only a Mappix can turn a kanban of columns into a place you can actually explore.
