> Nestrix is a burrowing poke-issue that tidies the Region Safari session sidebar. Today every agent it spawns appears as an identical L1 session — all stamped "board automation (0)" — scattered flat beneath the workspace, so trainers can't tell who is working on what. Nestrix gathers those sessions into one labeled nest per issue and tags each with the agent inhabiting it (Professor, Engineer, League…), so the sidebar reads as "this issue → these agents." It first sniffs the existing workflow-agent view for reusable burrows before digging new ones into github-app or Region Safari, always preferring to reuse a den over carving fresh core code.
