# Lassoon — Poke-issue-dex №64

*The Strategy Pokémon*

![Lassoon](lassoon.png)

**Type:** plan

**Rank:** hard

**Species:** Strategy Pokémon  
**Height:** 1.9 m   **Weight:** 9.3 kg

> Lassoon is the Roundup Pokémon: it lives on the Agent Workflow View and dreams of herding many issuemon at once. Today a trainer can only nudge one agent node at a time, so rearranging a busy board is slow and tedious. Lassoon brings figjam-style multi-select — shift-click to add nodes to a group, or drag a marquee bounding box so everything it touches or contains is lassoed — then drags the whole herd to a new spot in a single motion. It never drops a node from its lasso and always releases the group exactly where the trainer lets go.
